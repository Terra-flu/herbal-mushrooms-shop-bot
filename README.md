# herbal-mushrooms-shop-bot
Telegram bot for herbal and mushrooms products and consultations
# 🌿 Herbal Shop Bot

Telegram бот-витрина для продажи лекарственных растений, грибов и консультаций.

## 🚀 Как запустить на Render.com

1. Зарегистрируйся на [render.com](https://render.com)
2. Создай **Web Service**
3. Подключи этот репозиторий
4. В настройках укажи:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
5. Добавь переменные окружения:
   - `BOT_TOKEN` — твой токен бота
   - `ADMIN_ID` — твой Telegram ID (можно узнать через @userinfobot)

## 📦 Что включено

- Каталог товаров (растения)
- Каталог услуг (консультации)
- Кнопка «Заказать» → отправляет заказ админу
- Простое меню, фото, описание
